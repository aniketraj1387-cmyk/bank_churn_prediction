# Dashboard extracts

Three CSVs, all regenerated by the last cell of `notebooks/02_model.ipynb`.

**churn_by_segment.csv** - one row per segment (geography, gender, age band,
tenure band, product count, activity), with customer count and churn rate.

**risk_scores.csv** - all 10,000 customers with attributes, model churn
probability, risk band (high = above the 0.73 operating cutoff) and an
`in_test_set` flag. Train rows are scored in-sample; filter to
`in_test_set = 1` for honest performance views.

**cost_curve.csv** - threshold, tp/fp/fn counts and expected annual savings
from the cost analysis (assumptions in the model notebook).

## Dashboard plan (Tableau Public)

Four views I want to build:

1. **Where churn concentrates** - churn_pct bars by segment, small multiples
   per dimension, reference line at the 20.4% base rate. From
   churn_by_segment.csv.
2. **Risk map** - high-risk customer share by geography x age band, average
   balance in the tooltip. Shows where the model points and how much money
   sits there. From risk_scores.csv.
3. **Target list** - high-band customers sorted by balance: id, geography,
   age, products, active, balance, churn_prob. The sheet a retention team
   would actually work from. From risk_scores.csv.
4. **Operating point** - savings vs threshold line with a reference line at
   0.73. From cost_curve.csv.

Global filters: geography, age band, activity. Big numbers up top: base
churn (20.4%), share of book flagged (15%), expected annual savings.
